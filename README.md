# FonOpt

App Android de diagnóstico del rendimiento del teléfono.

## Fase 1
- Resumen de almacenamiento interno.
- Top 10 de apps por espacio ocupado (requiere "Acceso a uso").

## Instalar
Cada push compila el APK en GitHub Actions y lo publica en
**Releases → FonOpt (última versión de prueba)**. Descarga `app-debug.apk`
desde el celular e instálalo (permite "instalar apps desconocidas" la primera vez).
